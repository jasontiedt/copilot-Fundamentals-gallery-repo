# Lab 5: Debug, Document & Delegate

**Scenario:** Three real-world finishers. First you'll **debug** a genuine bug hiding in the code (the one your Lab 3 test already caught). Then you'll **document** your work with Copilot. Finally, you'll **delegate** a follow-up task to the **Copilot coding agent** and review the PR it opens for you — a preview of asynchronous, agent-driven development.

**Estimated Time:** ~22 minutes *(bonus lab)*

> **Prerequisite:** Finish [Lab 3](../03-unit-testing/README.md) — you'll re-enable the test you quarantined.

## 🌐 Pick your language

- 👉 [TypeScript / React](typescript.md)
- 👉 [Python](python.md)
- 👉 [Java](java.md)
- 👉 [C#](csharp.md)

## What You'll Learn
By the end of this lab, you will:
- [ ] **Debug** a failing test with `/fix` and Copilot's error explanations
- [ ] **Document** code with `/doc` and generate a README section
- [ ] **Delegate** a task to the Copilot coding agent from a GitHub issue
- [ ] Review an agent-generated Pull Request
- [ ] **Ship it**: push, open a PR, and get a Copilot review

## 🧩 The stages

| Stage | Focus | Feature | ~Time |
| ----- | ----- | ------- | ----- |
| 1 | Debug | `/fix`, explain errors, re-enable a test | 6 min |
| 2 | Document | `/doc`, generate docs | 5 min |
| 3 | Delegate | Create an issue (MCP), assign Copilot | 6 min |
| 4 | Review the agent | Inspect the agent's PR & session | 3 min |
| — | **Ship it** | Push → PR → Copilot review | 2 min |

## 🎁 What you'll take home

- Experience fixing a real bug guided by a test
- Generated documentation
- Your first **delegated** task and agent-authored PR
