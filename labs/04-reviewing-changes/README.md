# Lab 4: Reviewing Changes

**Scenario:** Great code isn't just written — it's **reviewed**. In this lab you'll practice every layer of Copilot-assisted review: inline review while you code, a full change review in Source Control, an AI-generated commit message, and finally a **Copilot review on your Pull Request**. You'll finish by capturing your team's standards so every future review is consistent.

**Estimated Time:** ~18 minutes

> **Prerequisite:** Finish [Lab 1](../01-personalize-and-standardize/README.md) (you'll reuse your **Reviewer** agent). Non-TypeScript tracks work in the [`labs/starter/`](../starter/) module.

## 🌐 Pick your language

- 👉 [TypeScript / React](typescript.md)
- 👉 [Python](python.md)
- 👉 [Java](java.md)
- 👉 [C#](csharp.md)

## What You'll Learn
By the end of this lab, you will:
- [ ] Use **inline review** on a selection
- [ ] Run a **Source Control** review of all your changes
- [ ] Generate a **commit message** with Copilot
- [ ] Request a **Copilot review on a Pull Request** and triage its comments
- [ ] Capture team review standards as a reusable **PR template + review instructions**

## 🧩 The stages

| Stage | Focus | Feature | ~Time |
| ----- | ----- | ------- | ----- |
| 1 | Make a diff | A small Copilot-made change to review | 3 min |
| 2 | Inline review | Right-click → Review | 3 min |
| 3 | Whole-change review | Source Control code review | 4 min |
| 4 | PR review | Push, open PR, add **Copilot** as reviewer | 5 min |
| 5 | Standardize | PR template + review instructions | 3 min |

## 🎁 What you'll take home

- A `pull_request_template.md` and a `code-review.instructions.md`
- A repeatable, multi-layer review habit
