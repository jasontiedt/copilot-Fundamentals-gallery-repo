# Lab 2: Core Development

**Scenario:** The gallery can list and filter photos, but the **"view details" experience is unfinished** — it's a placeholder. Your job is to complete it, using Copilot the way you would on a real ticket: understand the code, draft a plan, implement with AI assistance, and verify.

This is the **longest lab** and the heart of the track. You'll move through Copilot's modes deliberately — Ask → inline → Plan → Agent — and lean on the **custom instructions, prompt file, skill, and Reviewer agent you built in Lab 1**.

**Estimated Time:** ~40 minutes

> **Prerequisite:** Finish [Lab 1](../01-personalize-and-standardize/README.md) first — this lab reuses the artifacts you created. Non-TypeScript tracks work in the [`labs/starter/`](../starter/) module for your language.

## 🌐 Pick your language

- 👉 [TypeScript / React](typescript.md)
- 👉 [Python](python.md)
- 👉 [Java](java.md)
- 👉 [C#](csharp.md)

## What You'll Learn
By the end of this lab, you will:
- [ ] Explore unfamiliar code with **Ask mode**, `/explain`, and `#codebase`
- [ ] Use **inline suggestions** and **Next Edit Suggestions** to move quickly
- [ ] Draft a change with **Plan mode** before writing code
- [ ] Implement across files with **Agent mode**, guided by your Lab 1 artifacts
- [ ] Run, verify, and iterate with Copilot
- [ ] **Ship it**: push, open a PR, and get a Copilot review

## 🧩 The stages

| Stage | Focus | Feature | ~Time |
| ----- | ----- | ------- | ----- |
| 1 | Understand the code | Ask, `/explain`, `#codebase` | 6 min |
| 2 | Move fast | Inline & Next Edit Suggestions | 8 min |
| 3 | Think first | Plan mode | 6 min |
| 4 | Implement | Agent mode + your Lab 1 artifacts | 12 min |
| 5 | Verify | Run, test, iterate (`/fix`) | 5 min |
| — | **Ship it** | Push → PR → Copilot review | 5 min |

## 🎁 What you'll take home

- A completed feature built end-to-end with Copilot
- Muscle memory for the **Ask → Plan → Agent** workflow
- Proof that your Lab 1 instructions/skill actually shape generated code
